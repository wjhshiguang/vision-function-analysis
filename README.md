# 视功能自动分析工作台

眼镜店 / 视光师专用工具：录入视功能检查数据 → 自动分析 → 生成报告 → 管理复查提醒。

## 功能

- **检查录入**：屈光、调节（NRA/PRA/BCC/AMP/调节灵敏度）、双眼视（隐斜/融像/AC-A/集合近点）分组录入，数值字段为滚轮选择器
- **自动分析**：按指标准则判定异常、交叉诊断、严重度分级
- **报告生成**：结构化报告，可复制为文本
- **复查管理**：自动生成复查日期，「今天要处理」置顶逾期项
- **顾客档案**：全部记录检索与回溯

## 符号约定

- PRA 记录为**负值**，绝对值越大越好
- **外隐斜记为负值**，内隐斜记为正值

## 数据说明

所有数据仅保存在**使用者本机浏览器**（localStorage），不上传任何服务器。
建议定期使用页面内的「导出 JSON 备份」保存数据。

## 使用

打开 GitHub Pages 链接即可使用。手机端可通过浏览器「添加到主屏幕」获得全屏 App 体验。

## 技术

单文件 HTML，CSS/JS 全内联，零外部依赖；PWA（manifest + Service Worker）支持离线打开。
